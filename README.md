# 🎥 Edit Studio - сайт + Telegram-бот студии видеомонтажа

Современный темный сайт с неоновыми эффектами и отдельный Telegram-бот для заявок на эдиты.

## 🚀 Запуск

### Telegram-бот

Бот написан на Python без внешних зависимостей: Telegram Bot API, long polling и SQLite.

```bash
cp .env.example .env
# заполни BOT_TOKEN и ADMIN_IDS
python -m wasteware_bot
```

На Windows можно запускать из корня проекта:

```bat
copy .env.example .env
python -m wasteware_bot
```

Если запускаешь из папки `wasteware_bot`, сработает и так:

```bat
python main.py
```

Что умеет бот:

- пошагово собирает ТЗ на эдит;
- показывает прайс, портфолио и FAQ;
- хранит клиентов, заявки, статусы и события в SQLite;
- уведомляет админов о новых заявках;
- даёт админ-команды `/admin`, `/reply ID текст`, `/note ID текст`, `/broadcast текст`;
- сообщает клиенту о смене статуса заказа.

Переменные окружения описаны в `.env.example`.

### Вариант 1: Открыть напрямую
Просто откройте файл `index.html` в браузере (двойной клик)

### Вариант 2: Локальный сервер (рекомендуется)
```bash
# Если установлен Python
cd c:\script\website
python -m http.server 8000
```
Затем откройте в браузере: `http://localhost:8000`
