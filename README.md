# 🎥 Edit Studio - Сайт студии видеомонтажа

Современный темный сайт с неоновыми эффектами для студии видеомонтажа.

## 🚀 Запуск

### Вариант 1: Открыть напрямую
Просто откройте файл `index.html` в браузере (двойной клик)

### Вариант 2: Локальный сервер (рекомендуется)
```bash
# Если установлен Python
cd c:\script\website
python -m http.server 8000
```
Затем откройте в браузере: `http://localhost:8000`

## 📁 Структура файлов

```
website/
├── index.html      # Основная страница
├── style.css       # Стили и анимации
├── script.js       # Интерактивность
└── README.md       # Инструкция
```
